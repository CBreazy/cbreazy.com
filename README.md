## Installation

1.  Clone the repository:

    ```bash
    git clone [https://github.com/CBreazy/cbreazy.com.git](https://github.com/CBreazy/cbreazy.com.git)
    ```

2.  Navigate to the project directory:

    ```bash
    cd cbreazy.com
    ```

3.  Install dependencies:

    ```bash
    npm install
    ```

## Usage

1.  Run the Next.js application (cbreazy.com):

    ```bash
    npm run dev
    ```

2.  Run Storybook (storybook.cbreazy.com):

    ```bash
    npm run storybook
    ```

3.  Run plates.cbreazy.com (if applicable, based on your setup):

    * If `plates.cbreazy.com` is a separate Next.js app within the same repo, you'll likely have a specific command for it in your `package.json`. Adjust accordingly.
